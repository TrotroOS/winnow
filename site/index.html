Winnow

Binary-only outreach pipeline: each candidate is POSSIBLE or NOISE — no scores, ranks, or fit numbers.

Operator documentation lives in the RUNBOOK on GitHub.

Run the pipeline

Dry-run and live operation run on your machine or in Docker — not on Vercel.

  • Host: python -m winnow.run --config config_community.yaml --limit 50 --dry-run
  • Docker: docker compose --profile manual run --rm dry-run (see RUNBOOK)
